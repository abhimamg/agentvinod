# Personal Strategy & Thinking Workspace

This repository serves as a personal workspace designed for strategising, brainstorming ideas, planning events, and managing tasks. It is optimised for AI agents (including Antigravity and Jules) acting as concise, direct strategic partners.

## Workspace Structure

- `strategy/`: High-level strategic plans, roadmaps, and core objectives.
- `ideas/`: Brainstorming notes, concept drafts, and exploratory research.
- `events/`: Event planning files, agendas, timelines, and post-event reviews.
- `tasks/`: Task tracking lists, action items, and operational logs.
- `scripts/`: Python and Bash utility scripts for workspace management and task automation.
- `.agents/`: Local AI agent skills (`find-skills`, `grill-me`, and `uv-package-manager`).

## Agent Instructions

Full agent behavior guidelines, language rules (British English, structured numbered lists), task branching directives, and skill execution workflows are detailed in [`AGENTS.md`](./AGENTS.md).
